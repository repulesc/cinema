# Not for pasting into the HUD

`cinema_director_full.lsl` is the complete (v1.0.2) director with ensembles, long shots, speaker cut and style presets.
It is about 1,500 lines (~100 KB of compiled code) and does **not** fit in one 64 KB Mono script.
It is kept here as the source to split into several scripts later; the lean director in `src/` is what runs.
